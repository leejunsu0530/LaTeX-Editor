# LaTeX-Editor
인텔리센스, 단축 버튼, 자연어 처리 지원

- 아마 github pages 기반 html이나, gradio로 구현할 듯.
- 다른 곳에서 latex 문법 지원 필요
- 인텔리센스 지원
- AB라 적어놓고 드래그해서 { 입력시 {AB}꼴이 되게.
- ...을 입력하면 \cdots로 바꿔주고 vector라 입력하면 \overrightarrow{}로 바꿔주는 등의 자동화 단축키 기능
- 목표로 하고 있는 사이트는 [https://latexeditor.lagrida.com/](https://latexeditor.lagrida.com/)
- 기능
    - 스페이스바 2번 -> \quad
    - 1/3은 자동으로 분수로
    - R입력하면 \mathbb{R}로
